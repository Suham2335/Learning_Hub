## Project Description

This project is a responsive educational website called LearnHub. It contains a navigation bar, introduction section, course cards, contact section and footer.

The website contains six course cards with images, titles, descriptions, categories, course information and buttons.

The layout is responsive and changes according to the screen size.

- CSS Flexbox

## Key Concepts Learned

### Semantic HTML

I learned how semantic elements make the structure of a webpage easier to understand. I used elements such as header, nav, main, article and footer.

### CSS Selectors

I learned how CSS selectors can be used to select HTML elements and apply styles to them.

### Box Model

I learned how margin, padding, border and content affect the size and spacing of elements.

### Flexbox

I used Flexbox to arrange and align the navigation bar items horizontally.

### CSS Grid

I used CSS Grid to arrange the course cards into three columns on larger screens.

### Hover Effects

I used the :hover selector to change the appearance of navigation links and buttons when the mouse moves over them.

### Responsive Design

I used media queries to change the layout for tablet and mobile screen sizes.

## Challenges and Solutions

### Challenge 1

Initially, keeping the cards properly aligned was difficult because the screen size changes.

I solved this by using CSS Grid and responsive media queries.

### Challenge 2

The navigation items did not fit properly on smaller screens.

I solved this by changing the navigation layout to a vertical arrangement using a media query.
